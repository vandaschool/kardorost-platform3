# Kardorost Next

A fresh Laravel 13 / PostgreSQL / Vue 3 / Inertia 3 implementation of Kardorost.

This delivery implements account security, scoped roles and panel shells, course/cohort creation, enrollment capacity, a Zibal adapter, organization membership, course classrooms, lesson progress, live-session links, private assignment submissions, feedback history, attendance internal notifications, installment schedules, private bank-transfer receipts, payment allocation an admin finance queue, free consultation scheduling, direct booking, human coordination requests, cancellation history and shared session outcomes, paid consultation reservations with expiry, verified gateway callbacks and refund liabilities after cancellation. It is the foundation increment, not the completed platform.

See [the Persian installation and delivery guide](README-FA.md) for setup, completed functionality, remaining modules, verification results, and integration limitations.
