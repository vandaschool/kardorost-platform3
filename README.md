# Kardorost Next

A fresh Laravel 13 / PostgreSQL / Vue 3 / Inertia 3 implementation of Kardorost.

Implemented modules include secure accounts and scoped panels, course enrollment and capacity, learning rooms and private submissions, organization reports, installment billing, transfer receipts, consultation scheduling and gateway verification, a private manual refund workflow, and organization seat quotas with atomic group enrollment and scoped CSV exports. Organization membership now supports seven-day phone invitations, explicit acceptance after phone verification, and private UTF-8 CSV previews for up to 100 rows. Invalid rows block confirmation; normalized duplicates, existing members and existing invitations are skipped. Preview confirmation is creator-scoped, expires after 15 minutes and is idempotent. Neither bulk import nor the legacy add-member endpoint creates immediate membership or provisions accounts. Invitations use internal notifications and can be discovered after normal registration; invitation SMS is optional through a durable database outbox. Melipayamak REST and console pattern adapters support immediate OTP submission and queued organization invitations. Each invitation revision permits one provider attempt; duplicate workers cannot resend it, ambiguous outcomes remain in review, and interrupted attempts are reconciled without automatic resend. Provider acceptance is distinct from handset delivery. Real credentials/templates and live delivery remain unverified; delivery receipts and consultation reminders are incomplete. Sponsored seats share cohort capacity with personal reservations and do not create personal tuition invoices. Internal contract invoices now support immutable issuance, full or partial gateway and independently reviewed transfer payments with a cumulative allocation ledger, and scoped organization access. Original invoice totals stay fixed; late or concurrent funds exceeding the remaining balance are retained in review without allocation. Current organization managers can request full manual refunds of captured unallocated corporate funds. Admin review and private transfer evidence are separate steps, bank details are encrypted, and former payers have no personal access to organization evidence. Refunds preserve invoice allocations and balances. Allocated-fund refunds, credit transfers between invoices, dated organization installment schedules, formal tax/accounting integration and automatic license purchases remain incomplete.

Consultation entitlements can now be issued by admins against a reviewed source reference, scoped to one student, coach, exact session duration and expiry date. Students explicitly select a grant for direct or human-coordinated bookings. Each confirmed session consumes a ledger entry; cancellation before the start releases it once, while completion and no-show retain consumption. Booking keeps the listed tariff but creates no separate payment. Existing confirmed sessions survive grant suspension or expiry changes. Manual grant issuance does not record a purchase. Paid personal course purchases can now include frozen consultation terms per enrollment billing version. Admins explicitly choose activation after the first allocated payment or full settlement; verified gateway payments, approved transfer receipts and recovered payments share one issuance path. Replays and concurrent repairs cannot duplicate or extend grants. Unavailable participants block benefit issuance while preserving paid tuition and active enrollment, with an admin repair queue. Free, sponsored and pre-existing purchases do not receive retroactive benefits. Standalone consultation packages now have versioned admin offers, explicit student acceptance, frozen orders, dedicated verified Zibal callbacks and independently reviewed private transfer receipts. Fulfillment issues exactly one grant linked to the settled payment. Late or duplicate funds remain in review; admins can fulfill eligible frozen orders or use the existing full manual refund workflow for captured unallocated funds. Payment purpose guards isolate package funds from course, single-session and organization settlement. Sponsored consultation bundles, cancellation/refunds for already issued package grants and benefit reversal following active-course cancellation remain incomplete.

Course certificates now use cohort-specific selected lesson, attendance and latest graded-assignment criteria, with optional verified personal tuition settlement. Students explicitly confirm their name and consent to link-based public verification. Each request freezes its policy; admins re-evaluate current evidence and explicitly review before issuing one immutable certificate per enrollment. Anonymous token-based verification exposes only the agreed certificate fields, supports browser print/PDF and reflects versioned revocation. Instructors and selected organization managers see scoped completion status without verification tokens or private revocation notes. Lesson completion remains self-reported, issuance is manual, and existing learning access stays active. Reissue/correction, request withdrawal, QR codes, signed documents and server-generated PDFs remain incomplete.

Cohort-scoped questions and discussions now support active classmates, the currently assigned instructor and admins. Posting has explicit classroom visibility in the form, plain text rendering and UUID-based replay protection. Authors can edit their own message with version checks; every revision remains available to current staff. Moderation can pin, lock or hide a topic or message without deleting history. Student DTOs redact hidden content and internal reasons; a hidden topic's owner sees only a placeholder. Authors/staff can select a visible reply to a question, and edits/hiding invalidate stale selection. Generic internal notifications link to the correct paginated post and do not copy content that might later be hidden. Organization roles alone grant no discussion access. Attachments, nested replies, mentions, private messaging, title editing and live chat remain incomplete.

Versioned cohort surveys now support five-option ratings, short text, encrypted resumable drafts and immutable final submission. Admins explicitly publish an identified or aggregate report mode. Students see that scope before answering. Aggregate reports suppress each individual question until its own minimum response count is met, and expose no respondent identities, timestamps or per-person rating rows. Current instructors/admins can view scoped reports; individual draft pages remain owner-only. Receiving windows and extensions are versioned and audited. Educational feedback is separate from psychometric assessment scoring. CSV exports and final-response correction remain incomplete.

The assessment infrastructure supports immutable publications, resumable encrypted answers and versioned reports for five-option subscale sums with reversed items. Real instruments and scoring keys will be selected later; no questionnaire content is seeded into the application. Other instrument types, paid assessments, career reports and AI interpretation remain incomplete.

See [the Persian installation and delivery guide](README-FA.md) for setup, completed functionality, remaining modules, verification results, and integration limitations. This repository contains incremental working modules, not the completed platform.


Private support now covers all four roles, optional enrollment-scoped educational threads, current-instructor authorization, encrypted message bodies/history reasons, private authorized downloads, and admin-only notes. Public replies update the waiting state; resolve/close/reopen and private admin assignment are revision-controlled and audited in the ticket history. UUID replays do not duplicate messages/files; transactional failures clean up uploads. Generic internal notifications contain no private message content. The shared paginator supports both existing Laravel link arrays and full pagination objects. Verification: PostgreSQL 509 tests / 4066 assertions, SQLite 442 passed / 67 PostgreSQL-only skipped / 3685 assertions, six date tests, Pint, production build, and local three-role/mobile browser flow including legacy next-page navigation. Live chat, arbitrary direct messages and ticket SMS remain incomplete.


Organization membership now supports student departure, selected-manager removal, fresh consent for rejoining, and admin-controlled multiple managers. Every membership generation has a unique key, preventing stale tabs from removing a later membership or promotion. Ending membership invalidates replay of the old accepted invitation and immediately removes personal-report/private-learning-file access, while preserving existing enrollments, historical consumed seats and financial contracts. Admin manager revocation requires another active, verified manager with the organization role. Account role changes remain independent; other organization roles are preserved. Initial organization creation now also enforces verified manager phones, and account updates take the user lock before role writes. PostgreSQL: 531 tests / 4214 assertions; SQLite: 461 passed / 70 PostgreSQL-only skipped / 3817 assertions; six date tests, Pint, build, and local membership/manager/mobile browser flows passed. Seat recycling, dated corporate installments and financial course cancellation remain incomplete.


The public site now provides a server-rendered Persian glass homepage, published course/cohort catalog with real shared capacity, a journal and standalone pages. Blade delivers crawlable content and metadata without client JavaScript; canonical/Open Graph tags, an XML sitemap and robots are included. Private class links, accounts and drafts stay behind their existing access checks. Admin content authoring separates private drafts from immutable explicit publications, supports withdrawal/restoration with revision locks, and renders plain text with HTML escaping. Sitemap iteration omits article bodies. Public dates enhance to Persian/Tehran with an explicit Gregorian fallback. Course entry resumes after password login. No legacy users, fake testimonials/statistics or psychometric instruments were seeded.
